# 🚰 Sistema de Monitoramento de Reservatório de Água

Um sistema simples em Python executado no terminal para monitoramento de níveis de reservatórios de água. O programa solicita o nível atual da água e exibe uma mensagem de status com alertas visuais coloridos utilizando a biblioteca **Colorama**.

---

## 📋 Tabela de Níveis e Alertas

| Nível | Situação | Cor do Alerta |
| :---: | :--- | :--- |
| **1** | Muito baixo (crítico) | 🔴 Vermelho |
| **2** | Baixo | 🟡 Amarelo |
| **3** | Médio | 🟢 Verde |
| **4** | Alto | 🔵 Ciano |
| **5** | Muito alto (alerta) | 🟦 Azul |

---

## 🚀 Tecnologias Utilizadas

- **Python 3.10+** (utiliza sintaxe `match/case`)
- **[Colorama](https://pypi.org/project/colorama/)**: Biblioteca para estilização de cores e texto no terminal.
